# SWYNEX – AI-Based Student Query Classification System

## 📌 Project Overview

The AI-Based Student Query Classification System is a machine learning project designed to automatically classify student queries into different categories.

The system analyzes the text entered by a student and predicts the appropriate category, making query management easier and more organized.

It uses Natural Language Processing (NLP) techniques and machine learning algorithms to understand text patterns and perform classification.

## 🎯 Objectives

- Automate the classification of student queries.
- Reduce manual effort in organizing student requests.
- Explore practical applications of Artificial Intelligence and Machine Learning.
- Build a simple and efficient text classification system.

## ⚙️ Key Features

- Accepts student queries as text input.
- Automatically identifies the query category.
- Supports four predefined categories:
  - Academic
  - Technical
  - Administrative
  - Placement
- Provides instant classification results.
- Uses a trained machine learning model.
- Evaluates model performance using standard metrics.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Python | Programming language |
| Pandas | Dataset management |
| Scikit-learn | Machine learning |
| TF-IDF | Text feature extraction |
| Logistic Regression | Classification algorithm |

## 🔄 Working Process

1. Collect and prepare student query data.
2. Clean and preprocess the text.
3. Convert text into numerical features using TF-IDF.
4. Train the Logistic Regression model.
5. Accept a new student query.
6. Predict and display the appropriate category.
